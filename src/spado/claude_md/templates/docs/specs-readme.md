# Feature specs

One file per feature: `docs/specs/<feature-slug>.md`, based on [_template.md](_template.md).

Write the spec before implementing. Agents read it to plan, write tests from the acceptance criteria and review the result.
With the `feature-spec` skill installed, ask Claude: "write the spec for <feature>".

## Backlog

Ordered list of features, dependencies first. `/kickoff` and the feature skills read it.
